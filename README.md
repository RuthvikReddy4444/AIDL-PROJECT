# 🍎 AIDL PROJECT – Fresh and Rotten Fruit Classification

## 📌 Project Description
This project focuses on developing an AI-based fruit classification system using Deep Learning and Computer Vision. The system identifies whether a fruit is **Fresh or Rotten** by analyzing its image.

## 🎯 Objective
To build and train a deep learning model that can automatically classify fruit images into two categories:
- **Fresh** – Fruits in good condition.
- **Rotten** – Fruits showing signs of spoilage.

## 🛠️ Technologies Used
- Python
- Google Colab
- TensorFlow / Keras
- Deep Learning
- Convolutional Neural Networks (CNN)
- Computer Vision
- Google Drive

## ⚙️ Project Workflow
1. Dataset collection and preparation.
2. Image preprocessing and augmentation.
3. Model training and validation.
4. Performance evaluation.
5. Fresh and Rotten fruit prediction.

## 🚀 Expected Outcome
An image-based classification system that predicts whether a fruit is Fresh or Rotten and provides prediction confidence.

## 📂 Project File
- `AIDL_PROJECT.ipynb` – Jupyter Notebook containing the implementation, model training, evaluation, and prediction workflow.
